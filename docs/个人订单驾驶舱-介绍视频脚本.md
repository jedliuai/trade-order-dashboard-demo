# 个人订单驾驶舱｜介绍视频脚本

适用方向：社交平台上的个人项目展示，同时让有订单管理需求的人看懂用途。

形式：第一人称中文旁白＋网站录屏。目标时长约 2 分 15 秒，时间码用于剪辑参考，实际以自然朗读为准。

核心表达：把订单进度、回款和利润放在一起，让每天该跟进什么更清楚。

推荐标题：**订单走到哪了，钱回来了吗？我做了一个个人订单驾驶舱**

封面文字：**订单、回款、利润，一屏看清**

## 可选加镜：工作汇报（约 15 秒）

适合成片需要强调汇报功能时，加在导出之后；加入后总时长约 2 分 30 秒。

画面：系统设置 → Telegram 汇报 → 选择周期 → 生成汇报预览，停留在摘要内容。

旁白：**“工作汇报也可以先生成预览。需要发送时，配置好 Telegram，再手动确认，就能把当前身份范围内的经营摘要发给指定接收人。”**

字幕：**先预览，再确认发送**。

录屏只展示预览即可，不需要实际发送消息。

## 录制时记住这几件事

1. 浏览器使用 Microsoft Edge。全程只录本演示项目及它新生成的虚构报表，不使用旧项目截图、真实客户资料或历史业务文件。画面角落保留小字“本地演示版｜全部业务数据虚构”。
2. 提前选好一个有合同、联系单、批次、发货和回款记录的虚构客户。合同至收款段尽量沿用这个客户；如果切换订单，画面明确呈现新编号，避免剪辑成同一笔订单已完成全部流程的假象。
3. 制剂订单用来展示质量审核、排产、入库、放行；原料药不走这套完整生产节点。录屏前确认所选联系单类型。
4. 每个镜头只突出一个重点。点击和加载可以剪短，进度节点、状态和图表停留两三秒。不要逐个打开所有菜单，也不用完整录制填写表单。
5. 分析和导出先选有数据的时间范围，不强求当月。旁白不写死金额和百分比，避免本机数据变化后对不上。
6. 主片不必讲技术栈。演示身份只用于展示数据范围；排产日期由本地维护；Telegram 需要配置后手动确认发送。不要加上“生产级权限”“自动同步生产”“每天自动推送”等现版本没有的宣传。
7. 先录一遍旁白，再按旁白节奏补录画面。背景音乐以不遮盖人声为准；短字幕强调观点，完整口播字幕用于辅助理解。
