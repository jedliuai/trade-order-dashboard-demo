## 重点检查

1. 迁移不得重置已编辑数据；失败后保留原库和备份。
2. 收款早于联系单时可分配；新增联系单后预付款节点能重新计算；编辑分配不丢失审计历史。
3. 编辑准备中发货时原子更新、释放原占用；已发货和已开票记录不得错误删除。
4. 包装和车间快照兼容旧记录；导出筛选遵循当前身份和发货状态。
5. 前端只能访问同源本地接口；无 APS、Supabase、NAS 或生产系统连接；数据库、备份、密钥不进入 Git。
