# 最新本地版移植说明

上游来源：[jedliuai/trade-order-dashboard](https://github.com/jedliuai/trade-order-dashboard)，版本 `2edcc89ac2a30a6e6a289313d410fdfc09cd87de`，提交日期 2026-10-21。代码交付到演示仓库，原仓库不改动。

## 这次带来的主要功能

| 功能 | 本地实现 |
| --- | --- |
| 合同 | 累计预付款达标、0% 比例、复制与排序、按包装版本估算总体积/已发货/剩余体积 |
| 联系单 | 复制时检查当前包装版本、整套包装切换确认、制剂允许稍后补物料号、离开表单前检查未保存修改 |
| 收款 | 整笔银行到账台账、客户预存款、合同分配、累计进度、生效日及修改历史、会计文字复制 |
| 发货 | 整单编辑准备中安排、批次或联系单汇总、箱数和体积估算、实际发货校验、作废并复制 |
| 包装 | 版本车间快照、同车间版本延续、不同车间建立独立模板 |
| 分析和提醒 | 新版图表刻度、财年进度、合同内回款覆盖、提醒身份信息和列表改进 |
| 导出 | 十类已有报表，加放行申请、美金实际开票、预计开票；发货安排支持两种明细模式 |
| 操作体验 | 窄屏导航抽屉、窄屏发货摘要、键盘切换标签页、字段辅助信息和必填关联 |

APS 同步和自动跟踪已移除。QA、排产、入库与放行信息仍可本地维护；外部物料资料链接已替换为本地资料提示。没有生产系统、NAS、远程数据库或任务队列依赖。

## 启动与数据

已安装依赖时，在项目根目录执行 `npm run build`，然后 `npm start`；用 Microsoft Edge 打开 [本地版](http://127.0.0.1:8765)。首次安装先运行 `npm run setup`。开发模式仍可用 `npm run dev`。

数据库是 `data/demo.sqlite3`。启动会升级旧库，并把升级前的 SQLite 完整备份放进 `data/backups/`，不会重置旧记录，也不会把数据库或备份推到 GitHub。空库默认按启动当天生成虚构演示数据；指定 `--seed` 时才读取固定日期的种子 JSON。

已有数据库保留原日期，因此当前月可能没有新业务；这不是数据丢失。需要演示当前月时，可先下载 JSON 备份，再从设置页“备份并重置演示数据”，生成当天的完整虚构样例。

这仍是演示版：五个身份是演示范围切换，本地只允许环回地址，所有预置客户、公司及业务数据虚构。公网只读站点未在本轮部署。

业务口径与兼容细节见 [本轮口径记录](../具体要求/2026-10-28-最新功能本地移植口径.md)。
