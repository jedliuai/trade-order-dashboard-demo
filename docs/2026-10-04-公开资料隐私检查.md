# 公开资料隐私检查

检查日期：2026 年 10 月 4 日。范围为本演示仓库，不读取原业务系统，不读取本机真实环境凭据，不把原项目文件或私人素材复制进来。

## 当前文件与虚构数据

核对了本轮开始时的 229 个 Git 跟踪文件，覆盖前端、本地接口、Cloudflare Worker、测试、说明文档、工作记录、锁文件和虚构种子。检查包括常见访问令牌、机器人密钥、私钥、带凭据的连接地址、手机号、身份证号、邮箱、内网地址、旧服务域名，以及客户、产品、物料和业务编号。

没有发现上述格式的真实密钥、联系方式、内网地址或生产系统连接。外部地址逐类复核：运行所需的地址为用户指定的演示域名、可选 Telegram 官方接口和 Cloudflare 统计地址；依赖锁文件与发布说明中的其他链接为公开服务。测试中的 example 地址不连接实际业务系统。

种子里的 72 个客户、24 个产品及相关记录均使用明确的 DEMO / 虚构标识。客户、产品、合同、联系单、批次和物料等标识字段累计检查 25,505 项，没有发现缺少演示标识的实际业务实体。业务数据由本项目生成器创建，截图也只来自这个虚构演示站。

在部分测试样例中发现具体药品名称、一个具体公司名称及旧格式业务编号。已将它们替换为明确的虚构产品、虚构公司与 DEMO 编号；表单中的物料号、联系单号占位示例也已替换。测试的输入条件、计算金额、断言意义和业务规则保持一致。原文件仅留在本机 Git 忽略目录，便于追溯，没有删除不明来源材料。

## 提交历史与作者信息

本轮对此前全部 15 个提交、248 个不同文件内容版本进行了扩展检查。未发现常见密钥、个人联系方式或内网地址出现在文件内容中；三个历史测试文件仍含上述具体名称，因此仅修改当前文件不足以完成历史清理。

另外，历史提交的作者、提交者元数据含个人真实姓名与私人邮箱。当前项目的后续提交身份已单独改为 GitHub 用户名和 GitHub noreply 邮箱，没有修改全局 Git 配置。

历史清理会改变旧提交号，需要重写后推送。本轮已向用户请求确认；未经确认不替换远端历史。当前公开 main 的旧提交身份及历史样例仍属于待处理项，不能把当前源码清理等同于全部历史已经清理。

## 本轮公开截图与体验账号

五张截图均从 Microsoft Edge 的页面视口直接生成，不包含浏览器个人资料、桌面、地址栏或登录 Cookie。逐张检查了虚构客户、产品和编号；PNG 文件没有文本、EXIF 等附加元数据。总大小约 1.6 MiB。

本轮截图为经营首页、客户价值矩阵、客户集中度、客户产品分析和合同管理。专属展示横幅为新绘制的 SVG 数据链路示意，不使用原项目截图。

用户明确要求在 README 公开只读体验账号和密码，本轮按此授权加入。该共享演示入口不等同于 Telegram Token 或 Cloudflare 签名密钥；真实环境配置和 Worker Secret 继续不进入 Git。
