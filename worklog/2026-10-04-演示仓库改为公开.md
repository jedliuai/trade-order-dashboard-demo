# 演示仓库改为公开

## 做了什么

按这次要求，把 GitHub 上的 `jedliuai/trade-order-dashboard-demo` 从私有改成公开。先核对了本地 origin、远端 main 和账号的管理员权限，设置完成后再次读取 GitHub 可见性，并用不带登录凭据的 API 请求确认任何人都能访问仓库。

## 为什么做

这份仓库已经是独立的虚构业务演示项目，现在需要公开分享源码，让别人能够查看项目、学习实现和在本机运行演示。

## 值得记住的决策、坑和技术点

公开的不只是当前文件，提交历史也会一起开放，所以先获取远端状态，检查了全部 14 个提交、247 个不同的文件内容版本。没有发现常见格式的访问令牌、机器人密钥、私钥、带凭据的连接地址或内网地址；历史路径中也没有实际环境配置、数据库、备份、原始表格、图片或视频。唯一的环境配置示例只保留空值，虚构种子仍由本项目生成器创建。

只修改了这个演示仓库的 GitHub 可见性。应用代码、部署、业务规则和原项目均未变动，npm 的 `private: true` 仍用于防止误发布软件包，与 GitHub 仓库公开无关。本次验证针对可见性和公开内容，没有重跑应用测试；已有 CI 记录中存在失败，不能把这次设置验证当成应用 CI 全部通过。

## 一句话亮点

把“数据全是假的、流程真的能跑”的订单驾驶舱公开了，别人可以直接看源码、学实现、在自己的电脑上跑起来。
