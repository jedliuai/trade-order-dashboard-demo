# 粉丝现在可以用自己的资料试用了

以前发出去的网址，大家用的是同一个演示账号。这次把 deskdemo.jedliuai.com 换成了可以自行创建的个人工作区。第一次打开时拿到专属登录码，存好就能在另一台设备上继续录产品、客户和订单。每个人从空白开始，本地演示还可以用原来的虚构样例讲解。

用了专用 D1 保存试用数据。入口 Worker 先查登录会话，再把这个账号的业务资料交给私有 Python Worker。这样合同、发货、回款和利润继续用项目里原有的规则。写入时核对版本，新增产品时把主记录、别名和规格一次保存，中途校验失败会整笔撤回。

这版给每个工作区留了 1 MiB 的业务记录容量。模板 Excel 和 Word、Telegram、备份和重置都先留在本机。登录码只在创建时展示，云端保存摘要，当前还没有找回流程。

用 Edge 在正式域名创建了两个独立工作区，录产品、退出、重新登录，核对规格和别名。另一个账号的列表为空，也改不了、删不了或引用对方的产品。还走过手动汇率、客户、合同、联系单和经营指标。验收产生的工作区按本次生成的凭据摘要精确清理，回查剩余为零。自动化通过 417 项，云端和本地构建都通过。Windows 上发布用了 Node 22 LTS，绕开了本机 Node 24 偶发的原生进程退出问题。

一句话亮点：以前粉丝只能看我演示，今天他可以打开同一个网址，存下自己的第一个产品，明天再回来接着用。
