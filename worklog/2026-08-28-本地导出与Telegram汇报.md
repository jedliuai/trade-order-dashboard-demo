# 本地导出与 Telegram 汇报

1. 做了什么：给本地 SQLite 演示版补齐了 10 类 Excel/Word 导出，以及 Telegram 状态、预览和显式发送能力；还补了临时 SQLite 的回归测试。
2. 为什么做：旧导出和汇报依赖远程 worker/模板，不适合脱敏、可离线运行的演示版。现在报表全部由本地虚构数据即时生成。
3. 值得记住：筛选条件不能被某类报表“顺手忽略”，否则一个无效发货 ID 会变成全量泄露；金额/指标仍统一交给现有经营指标 RPC，避免出现两个口径。Excel 文本也要防公式注入。Telegram 配置只能报告是否配置，异常绝不带出 token 或 Chat ID。
4. 一句话亮点：一个没有外部业务依赖的订单驾驶舱，也能一键生成专业报表并安全预览 Telegram 经营汇报。
