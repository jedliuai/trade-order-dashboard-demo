# 导出语义修复

1. 做了什么：修正了发货明细利润按行对应、客户月报按币种拆分、人民币开票桥表筛选，并让生产协调、联系单辅助表和收货确认函带上真正有用的业务字段。
2. 为什么做：集成审查发现“文件能导出”不等于“数字口径正确”。特别是同一发货多明细、收款主单和合并发货开票，最容易出现重复、覆盖或跨币种相加。
3. 值得记住：利润视图本来就是逐发货明细行，绝不能再按 shipment ID 压扁；收款主单是权威总额，带 receipt_id 的分摊只是归属信息。应收与预存款必须分别截断为非负数，美元没有汇率时宁可留空也不要假装成人民币。
4. 一句话亮点：这次把“能下载的报表”升级成了“多明细、多币种、合并发货下也经得起对账的报表”。
