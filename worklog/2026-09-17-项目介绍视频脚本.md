# 项目介绍视频脚本

## 做了什么

给个人订单驾驶舱写了一版约两分十五秒的介绍视频脚本，放在 docs 里。旁白用第一人称讲，按时间配好了录屏页面、具体操作和重点字幕，也准备了标题、封面文字，以及一段可以按需加入的 Telegram 汇报介绍。

## 为什么做

网站功能不少，如果照着菜单一项项念，观众很难记住它到底解决什么问题。这次用“订单走到哪了、钱回来了吗、利润算清楚了吗”串起故事，让首页、履约、收款和经营分析各自有一个明确的出场理由。

## 值得记住的决策、坑和技术点

脚本根据当前 README 和页面源码核对，没有凭想象添加自动排产同步、定时推送或生产级认证。视频里明确说明客户和业务数据全部虚构，录屏只使用本项目及新生成的演示报表。

质量审核到放行的完整节点要用制剂联系单展示，原料药走不同流程。利润也保留现有口径：按实际开票月份匹配成本和汇率，条件不足显示待计算。镜头最好围绕同一个虚构客户展开，日期筛选则按演示数据实际覆盖的月份来选，不把金额写死在旁白里。

这轮只有文档新增，检查重点是文案与现有功能一致、时间码连续、没有敏感信息和无关文件混入提交；没有修改业务代码，也没有进行浏览器或运行时验收。

## 一句话亮点

用两分钟讲清一个订单驾驶舱：看得见订单走到了哪，也知道钱有没有回来、下一步该跟进什么。
